All three versions of the output are in the other folder.
The index.html file needed to use the advanced version is in the other folder

The goal is to be able to use the new version of wasm-bindgen with macroquad
You need to make changes to the js file and maybe the index.html
When you are done you should be able to run this program on the web.  
It needs wasm-bindgen to make use of the web-sys crate.

wasm-bindgen = "=0.2.118" --> in cargo.toml line 13
Run this to change version to newest:

cargo install -f wasm-bindgen-cli --version 0.2.118

To build normal web output:
cargo build --release --target wasm32-unknown-unknown


Build the Advance output:
wasm-bindgen "target/wasm32-unknown-unknown/release/db_test_new.wasm" --out-dir pkg --target web --no-typescript --weak-refs                             


To go back:
wasm-bindgen = "=0.2.106" --> in cargo.toml line 13
Run this to change version to newest:

cargo install -f wasm-bindgen-cli --version 0.2.106

Then build.
